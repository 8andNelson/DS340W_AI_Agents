Terminal Commands to know to Start and Run project.
  1) run virtual environment
                .venv\Scripts\Activate.ps1
     
  3) run the file with the prompt to designate the scope and domain of the project
                python run.py "machine learning for detecting credit card fraud"
     
  3) Reset any stored information on a previous project running. overwrites logs/project_state.json wiping out whatever was previously tracked
                python run.py --reset "your topic here"
